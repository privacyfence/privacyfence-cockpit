Branch runs: the steps only you can do

Manual runs can use another branch of the recipe repository. CI tests this against local git remotes; the one check below uses your real recipe repository and credentials. Ticks are remembered in this browser only.

Before implementation

Nothing to do. Run /implement on the plan right away.

After implementation

Do this once every phase is merged into feature/branch-runs, before the pull request merges.

1. Run a recipe from a non-configured branch of your real recipe repository

About 30 minutes

Use a separate Compose project and volume. This version upgrades the database to schema 3, and an older cockpit then refuses to open it.

  1. You should see the branch on GitHub next to your configured branch.

  2. git fetch origin feature/branch-runs
git checkout feature/branch-runs
docker build -t privacyfence-cockpit:branch-runs .

    The build ends with naming to docker.io/library/privacyfence-cockpit:branch-runs.

  3. docker compose -p cockpit-branch-test up -d
docker compose -p cockpit-branch-test logs cockpit

    The log prints a one-time setup code. Open http://127.0.0.1:8081 and set a password with it.

  4. The Code page shows the commit checked out and the Overview lists your recipes. Follow the user guide if anything here is new.

  5. The Run selected form has a Branch select whose first option is your configured branch marked (configured), and try/branch-run is in the list.

  6. Both runs finish. The run page has a Branch row with try/branch-run, the log header has # branch: try/branch-run and the branch's commit, and the unattended log shows your visible change.

  7. docker compose -p cockpit-branch-test exec cockpit git -C /data/repo log -1 --format=%H
docker compose -p cockpit-branch-test exec cockpit cockpit git status

    The commit is still your configured branch's, and /data/branches/try%2Fbranch-run exists.

  8. docker compose -p cockpit-branch-test exec cockpit cockpit run --branch try/branch-run <group/recipe>
docker compose -p cockpit-branch-test exec cockpit cockpit run --branch nope <group/recipe>; echo "exit $?"

    The first streams the branch's log and exits 0. The second prints There is no branch nope on the remote. and exit 1.
